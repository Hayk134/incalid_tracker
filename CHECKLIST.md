# Чек-лист исправления ошибок компиляции

## Шаг 1: Очистка кеша IDE
- [ ] Открыть Android Studio
- [ ] File → Invalidate Caches → Invalidate and Restart
- [ ] Дождаться перезагрузки и переиндексации (3-5 минут)

## Шаг 2: Проверка кода
- [ ] Нет ошибок в редакторе кода
- [ ] Все импорты разрешены (нет красных волнистых линий)
- [ ] Проект успешно синхронизирован с Gradle

## Шаг 3: Сборка Debug версии
```bash
./gradlew assembleDebug
```
- [ ] Сборка завершена успешно
- [ ] APK находится в `app/build/outputs/apk/debug/app-debug.apk`

## Шаг 4: Проверка функциональности
- [ ] Главный экран загружается
- [ ] Видна вкладка Карты с доступными местами
- [ ] Видна вкладка Места для браузера
- [ ] Видна вкладка Маршруты для планирования
- [ ] Видна вкладка Сохраненные для избранных мест

## Шаг 5: Подготовка к релизу (опционально)
- [ ] Обновлены версии в build.gradle.kts (versionCode, versionName)
- [ ] Создано хранилище подписей (keystore)
- [ ] Выполнена сборка Release версии:
```bash
./gradlew assembleRelease
```
- [ ] APK подписана и готова к публикации

## Шаг 6: Документация
- [ ] Прочитан PROJECT_README.md
- [ ] Прочитан QUICK_START.md
- [ ] Прочитан APK_BUILD_GUIDE.md (если планируется публикация)

## Если что-то не работает

### Ошибка: "Unresolved reference 'HotelResponse'"
- [ ] Выполнить File → Invalidate Caches → Invalidate and Restart
- [ ] Проверить, что папка `features/hotel/` полностью удалена
- [ ] Выполнить поиск и замену на `Hotel` → пусто

### Ошибка: "Too many arguments for 'constructor()'"
- [ ] Проверить, что InvestTravelApp.kt правильно регистрирует сервисы
- [ ] Убедиться, что нет импортов HotelsService
- [ ] Очистить Gradle: `./gradlew clean`

### Ошибка при синхронизации Gradle
```bash
./gradlew clean
./gradlew sync
```

### Если все еще есть ошибки
1. Закройте проект (File → Close Project)
2. Удалите папку `.gradle` в корне проекта
3. Откройте проект снова
4. Дождитесь полной переиндексации

## Готово!

После выполнения всех шагов проект должен:
- ✅ Компилироваться без ошибок
- ✅ Собираться в APK (Debug и Release)
- ✅ Содержать функции доступности вместо отелей
- ✅ Быть готовым к развертыванию на устройстве
